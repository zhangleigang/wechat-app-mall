# 收藏列表页面

## 功能概述

收藏列表页面展示用户收藏的所有问题，支持标签筛选、分页加载和下拉刷新。

## 页面结构

```
收藏列表页
├── 渐变头部
│   ├── 标题：我的收藏
│   └── 副标题：N 个收藏
├── 标签筛选区（横向滚动）
│   ├── 全部（显示总数）
│   └── 各个标签（显示使用次数）
├── 收藏列表
│   └── 收藏项
│       ├── 问题预览（最多50字符）
│       ├── 标签列表（最多5个）
│       └── 底部信息
│           ├── 来源信息（图标 + 名称 + 分类）
│           └── 时间
└── 空状态
    ├── 图标
    ├── 提示文字
    └── 登录按钮（未登录时）
```

## 数据流

1. **页面加载**
   - 检查登录状态
   - 获取 OpenID
   - 加载收藏列表
   - 加载标签列表

2. **标签筛选**
   - 点击标签 → 设置筛选条件
   - 重置分页 → 重新加载列表
   - 点击"全部" → 清除筛选

3. **分页加载**
   - 滚动到底部 → 检查是否有更多
   - 页码+1 → 追加加载数据
   - 显示加载状态

4. **下拉刷新**
   - 下拉触发 → 重置所有状态
   - 重新加载数据 → 显示成功提示

## API 调用

### getFavorites
```javascript
const result = await favoritesApi.getFavorites({
  openid: 'xxx',
  page: 1,
  pageSize: 20,
  tag: 'optional'  // 可选，标签筛选
});
```

### getTags
```javascript
const result = await favoritesApi.getTags(openid);
```

## 样式特点

- **渐变头部**：紫色渐变背景
- **标签筛选**：横向滚动，选中状态渐变背景
- **收藏卡片**：白色背景，圆角，阴影，点击缩放效果
- **标签徽章**：浅蓝色背景，圆角
- **来源图标**：Emoji 表情
- **响应式**：适配不同屏幕尺寸

## 交互细节

1. **点击收藏项** → 跳转到详情页
2. **点击标签** → 筛选该标签的收藏
3. **再次点击相同标签** → 取消筛选
4. **滚动到底部** → 自动加载更多
5. **下拉页面** → 刷新数据
6. **点击登录按钮** → 跳转登录页

## 性能优化
