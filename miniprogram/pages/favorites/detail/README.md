# 收藏详情页面

## 功能概述

收藏详情页面用于展示用户收藏的完整问题和答案，支持标签管理、删除和分享功能。

## 主要功能

### 1. 详情展示 (Requirements 6.1, 6.2, 6.3)

- **问题显示**: 完整显示收藏的问题标题
- **答案渲染**: 使用 towxml 组件渲染 Markdown 格式的答案
  - 支持标题、代码块、列表、链接等 Markdown 语法
  - 代码块自动语法高亮
- **元信息**: 显示来源类型、来源分类、收藏时间

### 2. 标签管理 (Requirements 7.1, 7.2, 7.3, 7.4, 7.5)

- **标签展示**: 显示所有关联的标签（最多显示5个，超过显示"+N 更多"）
- **添加标签**: 
  - 点击"添加"按钮显示输入框
  - 验证标签名称（非空，最多10个字符）
  - 检查重复标签
  - 实时更新UI
- **删除标签**:
  - 点击标签的关闭按钮
  - 显示确认对话框
  - 删除后实时更新UI

### 3. 删除功能 (Requirements 9.1, 9.2, 9.3, 9.4, 9.5)

- **删除确认**: 显示确认对话框，防止误删
- **撤销功能**: 
  - 删除后显示撤销提示（5秒）
  - 点击"撤销"按钮可恢复收藏
  - 5秒后自动返回列表页
- **震动反馈**: 删除和撤销操作提供触觉反馈

### 4. 分享功能 (Requirements 6.5)

- **分享到好友**: 
  - 显示问题预览和来源标签
  - 分享链接直接跳转到详情页
- **分享到朋友圈**: 
  - 支持分享到微信朋友圈（需开通）
  - 自定义分享标题和图片

## 技术实现

### 核心依赖

- **towxml**: Markdown 渲染组件
- **favorites-api**: 收藏功能 API 客户端
- **simpleAuth**: 用户认证模块
- **Vant Weapp**: UI 组件库

### 数据流

```
用户操作 → 页面事件处理 → API 调用 → 后端处理 → 更新本地状态 → UI 刷新
```

### 关键方法

- `loadDetail()`: 加载收藏详情
- `addTag()`: 添加标签
- `removeTag()`: 删除标签
- `deleteFavorite()`: 删除收藏
- `undoDelete()`: 撤销删除
- `onShareAppMessage()`: 分享到好友
- `onShareTimeline()`: 分享到朋友圈

## 样式设计

### 渐变背景

使用紫色渐变背景（#667eea → #764ba2），提供视觉层次感。

### 卡片布局

- 问题区域：白色卡片，圆角16rpx
- 标签区域：白色卡片，支持添加和删除
- 答案区域：白色卡片，towxml 渲染
- 元信息区域：白色卡片，显示来源和时间
- 操作按钮：白色卡片，删除和分享按钮

### 交互反馈

- 按钮点击：触觉震动反馈
- 加载状态：显示 loading 动画
- 错误提示：Toast 消息提示
- 撤销浮层：底部浮动提示，5秒自动消失

## 使用示例

### 从列表页跳转

```javascript
wx.navigateTo({
  url: `/pages/favorites/detail?id=${favoriteId}`
});
```

### 页面参数

- `id`: 收藏ID（必需）

## 注意事项

1. **登录验证**: 页面加载时检查用户登录状态
2. **数据验证**: 标签名称验证（非空，最多10字符）
3. **错误处理**: 所有 API 调用都有错误处理和用户提示
4. **内存管理**: 页面卸载时清除定时器
5. **列表刷新**: 删除后通知列表页刷新数据
