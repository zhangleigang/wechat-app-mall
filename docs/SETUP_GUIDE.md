## 🚀 配置步骤（5分钟）

### 第1步：准备收款码

1. 打开微信 → 我 → 服务 → 收付款 → 二维码收款
2. 点击"保存收款码"
3. 收款码图片已保存到相册

### 第2步：上传收款码

**方式A：使用免费图床（推荐）**

1. 访问 https://imgse.com 或 https://sm.ms
2. 上传收款码图片
3. 复制图片URL（类似：`https://s2.loli.net/2024/11/25/xxx.jpg`）

**方式B：使用微信云存储**

1. 打开微信开发者工具
2. 点击"云开发" → "存储"
3. 上传收款码图片
4. 右键图片 → 复制文件URL

### 第3步：配置到小程序

打开 `config.js` 文件，找到这一段：

```javascript
// 收款码配置（个人收款码方案）
paymentQrcode: {
  url: 'https://your-qrcode-url.com/qrcode.jpg', // TODO: 替换为你的收款码URL
  accountName: '收款人', // TODO: 替换为你的姓名
  enabled: true
}
```

**修改为**：

```javascript
// 收款码配置（个人收款码方案）
paymentQrcode: {
  url: 'https://s2.loli.net/2024/11/25/你的图片.jpg', // 粘贴你的收款码URL
  accountName: '张三', // 填写你的姓名
  enabled: true
}
```

### 第4步：测试

1. 在微信开发者工具中编译
2. 进入"会员套餐"页面
3. 选择任意套餐
4. 查看是否显示收款码
5. 测试复制订单号功能

## 📱 用户使用流程

1. 用户选择套餐（如：季度会员 ¥49.9）
2. 进入支付页面，看到：
   - 订单号（可复制）
   - 收款码
   - 支付说明
3. 用户长按收款码 → 识别二维码
4. 在微信转账页面：
   - 输入金额：¥49.9
   - 备注：订单号（如：ORD1732512345ABC）
5. 完成转账
6. 点击"我已支付"按钮
7. 等待你确认（5-30分钟）

## ⚠️ 重要提示

1. **收款码URL必须是HTTPS**
   - ✅ 正确：`https://s2.loli.net/xxx.jpg`
   - ❌ 错误：`http://xxx.jpg`（不安全）

2. **提醒用户备注订单号**
   - 页面上已经有明显提示
   - 用户可以一键复制订单号

3. **及时处理订单**
   - 建议每天固定时间处理（如早中晚各一次）
   - 或者收到转账后立即处理

4. **保存转账记录**
   - 微信转账记录可以作为凭证
   - 建议定期导出对账
