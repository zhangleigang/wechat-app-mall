### 3. 本地数据管理
```javascript
// 分享历史存储（最多100条）
const shareHistory = wx.getStorageSync('shareHistory') || [];
shareHistory.push(shareData);

if (shareHistory.length > 100) {
  shareHistory.splice(0, shareHistory.length - 100);
}

wx.setStorageSync('shareHistory', shareHistory);
```
