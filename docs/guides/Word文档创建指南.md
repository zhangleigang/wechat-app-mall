# Word文档创建指南 - 微信公众号文章

## 📝 创建步骤

### 1. 打开Word，设置基本格式
- 字体：微软雅黑或宋体
- 字号：正文14号，标题16-18号
- 行距：1.5倍行距
- 页边距：窄边距

### 2. 标题格式设置
```
标题1：面试刷题平台全面对比，选对工具很重要！
- 字体：微软雅黑，18号，加粗
- 颜色：深蓝色 #1f4e79
- 居中对齐

标题2：一、平台概览对比
- 字体：微软雅黑，16号，加粗
- 颜色：深灰色 #333333

标题3：2.1 平台介绍
- 字体：微软雅黑，15号，加粗
- 颜色：中灰色 #666666
```

### 3. 正文格式
```
正文：
- 字体：微软雅黑，14号
- 颜色：黑色 #000000
- 首行缩进：2字符
- 段落间距：段前6磅，段后6磅
```

### 4. 特殊格式处理

#### 表格格式：
- 边框：1磅，黑色实线
- 表头：深蓝色背景 #1f4e79，白色字体
- 奇偶行：浅灰色背景 #f2f2f2

#### 代码块格式：
- 字体：Consolas或等宽字体，12号
- 背景：浅灰色 #f5f5f5
- 边框：1磅灰色虚线

#### 重点文字：
- 加粗：重要概念和关键词
- 颜色：蓝色 #0066cc 用于链接和重点
- 背景高亮：黄色 #ffff99 用于特别重要内容

### 5. 插入元素
- 项目符号：使用圆点 • 或数字 1. 2. 3.
- 分隔线：插入 → 形状 → 直线
- 图片占位：插入文本框，写"[小程序码图片位置]"
