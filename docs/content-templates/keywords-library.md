## 关键词使用策略

### 标题优化
1. **主关键词前置**：将核心关键词放在标题前部
2. **长尾词组合**：结合多个相关关键词
3. **情感词点缀**：适当添加情感触发词
4. **控制长度**：保持15-25字的合理长度

### 内容优化
1. **关键词密度**：保持2-5%的合理密度
2. **自然分布**：关键词自然融入内容
3. **语义相关**：使用相关词和同义词
4. **标签优化**：合理使用H1-H6标签

### 平台适配
1. **微信公众号**：注重可读性和分享性
2. **知乎**：强调专业性和深度
3. **CSDN/掘金**：突出技术性和实用性
4. **牛客网**：关注面试相关性
