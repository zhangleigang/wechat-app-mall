```markdown
# HDFS面试题：HDFS的架构是什么样的？

## 📋 面试问题

**面试官问**：请简述HDFS的架构，包括主要组件和它们的作用。

## ⚡ 快速回答（2-3分钟版本）

### 核心要点
1. **主从架构**：HDFS采用Master-Slave架构，一个NameNode管理多个DataNode
2. **NameNode职责**：管理文件系统元数据，不存储实际数据
3. **DataNode职责**：存储实际数据块，定期向NameNode汇报

### 一句话总结
HDFS是主从架构的分布式文件系统，NameNode管理元数据，DataNode存储数据，通过数据分块和副本机制实现高可靠性。

## 📖 详细解析

### 1. 核心组件说明

**NameNode（主节点）**：
- 管理文件系统命名空间
- 维护文件与数据块的映射关系
- 处理客户端的文件访问请求
- 管理数据块的复制策略

**DataNode（从节点）**：
- 存储实际的数据块
- 定期向NameNode发送心跳和块报告
- 执行数据块的读写操作
- 根据NameNode指令进行数据块复制

### 2. 工作流程

**写入流程**：
1. 客户端向NameNode请求写入文件
2. NameNode检查权限并返回DataNode列表
3. 客户端与DataNode建立写入管道
4. 数据按块写入，每个块默认3个副本

**读取流程**：
1. 客户端向NameNode请求文件位置
2. NameNode返回数据块位置信息
3. 客户端直接从最近的DataNode读取数据
```
