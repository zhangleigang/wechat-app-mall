#### 高质量题目示例

**题目**：Spark中RDD、DataFrame、Dataset的区别是什么？

**标准答案**：
```
1. RDD (Resilient Distributed Dataset)
- 弹性分布式数据集，Spark的基础数据结构
- 不可变、可分区、可并行计算
- 提供丰富的转换和行动操作
- 编译时类型安全，但没有优化器

2. DataFrame
- 基于RDD构建的分布式数据表
- 具有Schema信息，类似关系型数据库的表
- 支持SQL查询和DSL操作
- 有Catalyst优化器，性能更好
- 运行时类型检查

3. Dataset
- Spark 1.6引入，结合了RDD和DataFrame的优点
- 编译时类型安全 + Catalyst优化器
- 强类型API，支持Lambda表达式
- 是DataFrame的超集（DataFrame = Dataset[Row]）
```

**加分回答**：
```
性能对比：
- RDD：无优化器，性能相对较低
- DataFrame：有Catalyst优化，性能较好
- Dataset：既有优化器又有类型安全，性能最佳

使用场景：
- RDD：底层操作、复杂的数据转换
- DataFrame：SQL分析、数据清洗
- Dataset：类型安全要求高的场景

发展趋势：
Spark 2.0后推荐使用Dataset API，DataFrame实际上是Dataset[Row]的别名
```
