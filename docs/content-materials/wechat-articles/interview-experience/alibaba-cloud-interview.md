## 一面：技术基础 + 算法（60分钟）

### 技术问题重点

#### 问题1：Flink如何实现Exactly-Once语义？

**我的回答**：
Flink通过以下机制实现Exactly-Once：

1. **Checkpoint机制**：
   - 定期对算子状态进行快照
   - 使用Chandy-Lamport算法保证一致性
   - Checkpoint Barrier在数据流中传播

2. **两阶段提交协议**：
   - Pre-commit阶段：准备提交但不真正提交
   - Commit阶段：收到checkpoint完成通知后提交
   - Abort阶段：checkpoint失败时回滚

3. **幂等性保证**：
   - Sink端支持幂等写入
   - 使用事务性连接器
   - 重复数据检测和去重

**面试官追问**：如果下游系统不支持事务怎么办？

**我的回答**：
- 使用幂等性写入：基于业务主键去重
- 实现自定义Sink：添加事务性支持
- 使用外部系统：如Redis做去重判断
- 业务层处理：在应用层实现幂等逻辑

#### 问题2：HBase读写性能优化有哪些方法？

**我的回答**：
**读性能优化**：
1. **RowKey设计**：避免热点，支持范围查询
2. **Bloom Filter**：减少不必要的文件扫描
3. **Block Cache**：缓存热点数据块
4. **预分区**：避免Region频繁分裂
5. **压缩算法**：选择合适的压缩方式

**写性能优化**：
1. **批量写入**：使用BufferedMutator
2. **MemStore调优**：合理设置刷写阈值
3. **WAL优化**：异步写入，合理设置副本数
4. **Compaction调优**：控制合并频率和策略

**面试官追问**：如何解决热点Region问题？

**我的回答**：
1. **RowKey加盐**：添加随机前缀分散写入
2. **预分区策略**：创建表时预先分区
3. **负载均衡**：手动迁移热点Region
4. **监控告警**：及时发现和处理热点

### 算法题

**题目**：给定一个大文件，如何找出出现频率最高的K个单词？

**我的思路**：
1. **分治策略**：将大文件分割成小文件
2. **本地统计**：每个小文件统计词频
3. **全局合并**：合并所有结果找出TopK
4. **优化策略**：使用堆排序和Hash分区

**代码实现**：
```python
def distributed_topk(file_path, k):
    # 1. 文件分片
    split_files = split_large_file(file_path, num_splits=10)
    
    # 2. 并行处理每个分片
    local_results = []
    for split_file in split_files:
        word_count = count_words_in_file(split_file)
        local_topk = heapq.nlargest(k, word_count.items(), key=lambda x: x[1])
        local_results.append(local_topk)
    
    # 3. 全局TopK合并
    global_count = defaultdict(int)
    for local_result in local_results:
        for word, count in local_result:
            global_count[word] += count
    
    return heapq.nlargest(k, global_count.items(), key=lambda x: x[1])
```
