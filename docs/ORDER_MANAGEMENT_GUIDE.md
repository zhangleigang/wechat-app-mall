# 订单管理系统使用指南

## 功能概述

订单管理系统帮助你追踪和核实用户的支付情况，防止欺诈行为。

## 主要功能

### 1. 自动记录订单
- 用户点击"我已完成支付"时，系统自动记录订单信息
- 记录内容：订单号、用户ID、套餐信息、金额、时间、设备信息
- 订单状态：待核实（pending_verify）

### 2. 订单管理页面
- 访问路径：个人中心 → 订单管理
- 显示所有订单记录
- 实时统计：总订单数、待核实数、已核实数、总金额

### 3. 订单筛选
- 全部订单
- 待核实订单（需要核对的）
- 已核实订单（已确认收款的）

### 4. 订单操作
- 查看详情：查看订单完整信息
- 标记已核实：确认收到款项后标记
- 复制订单号：快速复制用于核对
- 导出数据：导出为CSV格式，可在Excel中查看

## 使用流程

### 每日核对流程

**步骤1：打开订单管理**
```
个人中心 → 订单管理
```

**步骤2：查看待核实订单**
```
点击"待核实"标签
查看所有未核实的订单
```

**步骤3：打开微信收款记录**
```
微信 → 我 → 服务 → 钱包 → 账单
筛选"收入"记录
```

**步骤4：核对订单**
```
对比订单号（在转账备注中）
对比金额
对比时间
```

**步骤5：标记已核实**
```
确认收到款项的订单
点击"标记已核实"按钮
```

**步骤6：处理异常订单**
```
未支付但已开通会员的：
1. 记录用户ID
2. 联系用户确认
3. 如确认欺诈，添加到黑名单
```

### 导出订单数据

**用途：**
- 定期备份订单记录
- 在Excel中进行批量核对
- 生成财务报表

**操作：**
```
1. 点击"导出订单数据"按钮
2. 数据自动复制到剪贴板
3. 打开Excel，粘贴数据
4. 保存为Excel文件
```

**导出格式：**
```csv
订单号,用户ID,套餐名称,金额,时间,状态
ORDER_1234567890_ABC,user123,月度会员,29.9,2024-01-01 10:00:00,待核实
```

### 清理订单记录

**清空已核实订单：**
- 定期清理已核实的订单，保持列表简洁
- 建议：每周或每月清理一次
- 操作：点击"清空已核实"按钮

**清空全部订单：**
- ⚠️ 危险操作，会删除所有订单记录
- 建议：先导出备份再清空
- 操作：点击"清空全部"按钮

## 订单信息说明

### 订单号格式
```
ORDER_时间戳_随机码
例如：ORDER_1704096000000_ABC123XYZ
```

### 订单状态
- **pending_verify**（待核实）：用户已点击确认，但未核对收款
- **verified**（已核实）：已确认收到款项

### 用户信息
- **userId**：用户唯一标识
- **userInfo**：用户昵称、头像等信息
- **deviceInfo**：设备平台、系统版本等

## 防欺诈措施

### 1. 警告提示
用户点击"我已完成支付"时会看到：
```
⚠️ 支付确认

请确认您已完成 ¥29.9 的转账支付

订单号：ORDER_1234567890_ABC

虚假确认将导致账号被永久封禁
```

### 2. 订单追溯
- 记录完整的用户信息和设备信息
- 可以追溯到具体用户
- 便于后续处理

### 3. 黑名单机制
发现欺诈行为后：
1. 记录用户ID
2. 取消会员权益
3. 添加到黑名单
4. 阻止再次购买

## 数据安全

### 本地存储
- 订单数据存储在小程序本地存储中
- 存储键：`pending_orders`
- 数据格式：JSON数组

### 数据备份
建议定期导出订单数据进行备份：
- 每周导出一次
- 保存到云盘或本地
- 防止数据丢失

### 隐私保护
- 订单数据仅管理员可见
- 不会泄露给其他用户
- 符合隐私保护要求

## 常见问题

### Q1: 用户说已支付，但我没收到款怎么办？
A: 
1. 让用户提供支付截图
2. 核对订单号和金额
3. 检查微信收款记录
4. 如确实未收到，联系用户重新支付

### Q2: 发现用户未支付就开通了会员怎么办？
A:
1. 在订单管理中找到该订单
2. 记录用户ID
3. 联系用户确认情况
4. 如确认欺诈，取消会员并加入黑名单

### Q3: 订单记录太多，如何管理？
A:
1. 定期标记已核实的订单
2. 每周清空已核实订单
3. 导出重要数据进行备份

### Q4: 如何快速核对大量订单？
A:
1. 导出订单数据到Excel
2. 导出微信账单（微信支付商户平台）
3. 使用Excel的VLOOKUP函数批量匹配
4. 标记已核实的订单

### Q5: 订单数据会丢失吗？
A:
- 数据存储在本地，不会自动丢失
- 但如果用户清除小程序数据，会丢失
- 建议定期导出备份

## 统计分析

### 查看统计数据
订单管理页面顶部显示：
- 总订单数：所有订单总数
- 待核实：需要核对的订单数
- 已核实：已确认收款的订单数
- 总金额：所有订单的总金额

### 分析转化率
```
转化率 = 已核实订单数 / 总订单数 × 100%
```

### 分析欺诈率
```
欺诈率 = 未支付订单数 / 总订单数 × 100%
```

正常情况下，欺诈率应该 < 5%

```javascript
    system: "iOS 15.0",

  }

```

### 存储位置
```javascript
// 获取订单列表
const orders = wx.getStorageSync('pending_orders') || []

// 保存订单列表
wx.setStorageSync('pending_orders', orders)
```

### 扩展开发
如果需要后端API支持，可以在 `saveOrderRecord` 方法中添加：
```javascript
uploadOrderToServer(orderRecord) {
    wx.request({
        url: 'https://your-api.com/orders/record',
        method: 'POST',
        data: orderRecord,
        success: (res) => {
            console.log('订单已上传到服务器')
        }
    })
}
```
