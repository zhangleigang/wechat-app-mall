# 产品概述

AI面试助手是一款基于微信小程序的智能职业发展工具，专注于大数据领域的面试准备，帮助求职者提升面试竞争力。

## 核心功能

### AI功能（需会员）

**岗位分析**: 通过AI分析职位描述（JD）或岗位链接，自动提取核心技能、岗位职责，并生成预测面试问题，帮助求职者了解岗位要求和能力差距。

**简历解读**: AI驱动的智能简历分析功能，支持多种文件格式上传，自动解析简历内容，提供优化建议和岗位匹配度分析，帮助求职者完善简历。

**情绪小屋**: 提供面试压力管理和心理支持，通过AI对话帮助求职者缓解面试焦虑，提供放松技巧和应对策略。

### 知识库（部分免费）

**面试知识库**: 提供结构化的大数据技术面试题库，覆盖10+个主流技术分类（HDFS、Spark、Flink、Kafka、HBase、Hive、MapReduce、Yarn、Zookeeper、Flume等），包含200+精选面试问题和详细答案，支持分类浏览和关键词搜索。

**访问策略**:
- 免费用户：可以浏览题目列表和分类，了解知识库内容
- 会员用户：可以查看完整的题目详情和答案解析

### 个人中心

**用户管理**: 用户信息展示、会员状态查看、系统设置配置、意见反馈提交等功能。

## 目标用户

- 大数据/数据工程领域的求职者
- 准备技术面试的应届毕业生和在职人员
- 需要简历优化和面试辅导的技术人员
- 面临面试压力需要情绪支持的求职者

## 商业模式

### 会员付费制

用户需要开通会员后才能使用AI功能（岗位分析、简历解读、情绪小屋），知识库功能对所有用户免费开放。

### 会员套餐

- **月度会员**: ¥29.9 / 30天
- **季度会员**: ¥49.9 / 90天
- **年度会员**: ¥99.9 / 365天

### 会员权益

- ✅ 无限次使用所有AI功能（岗位分析、简历解读、情绪小屋）
- ✅ 查看知识库完整答案和详细解析
- ✅ 无限次数的AI对话
- ✅ 优先客服支持

### 支付方式

**收款码支付**: 用户选择套餐后，扫描个人收款码完成支付，点击"我已支付"后立即激活会员。

**技术实现**:
- 前端：使用 `utils/member-api.js` 对接后端会员服务，会员信息缓存10分钟
- 后端：member-service（基于OpenID）提供会员状态查询、开通续费、订单记录和对账功能
- 认证：knowledge-api 提供用户认证（JWT + OpenID）和微信登录
- 存储：会员数据和订单记录存储在 MySQL 数据库中

### 会员验证

系统会在以下场景验证用户的会员状态：

**AI功能**:
- 有效会员：直接使用功能
- 无效会员：自动跳转到套餐购买页面

**知识库**:
- 题目列表：所有用户可浏览
- 题目详情：需要会员才能查看完整答案
- 无效会员点击题目：提示开通会员并引导到购买页面

## 技术架构

### 前端
- 微信小程序（原生开发）
- 会员API客户端（`utils/member-api.js`）
- 收款码支付流程（保存到相册 → 微信扫一扫 → 支付 → 激活）
- 会员状态缓存（10分钟有效期）

### 后端服务

**knowledge-api** (端口3000，HTTPS 8443):
- 知识库数据API
- 用户认证（JWT + OpenID）
- 微信登录（wx.login → code2Session → OpenID）
- 静态文件服务（收款码图片）
- 生产地址：https://api.feelnow.cn:8443

**member-service** (端口3001):
- 会员状态管理（基于OpenID）
- 会员开通和续费
- 订单记录和查询
- 管理员接口（订单列表、会员列表、导出）
- 生产地址：http://47.95.196.190:3001

### 数据存储

- 知识库数据：JSON文件（knowledge-api/data/knowledge.json）
- 用户认证：JSON文件（knowledge-api/data/users.json，存储 OpenID 和用户信息）
- 会员数据：MySQL数据库（member-service，members表，主键为OpenID）
- 订单数据：MySQL数据库（member-service，orders表，关联OpenID）
- 前端缓存：会员状态缓存10分钟，减少API调用

## 产品特色

1. **专注垂直领域** - 专注大数据技术面试，内容精准专业
2. **AI驱动** - 智能分析岗位和简历，提供个性化建议
3. **免费试用** - 知识库题目列表免费浏览，降低使用门槛
4. **轻量付费** - 收款码支付，简单直接，无需复杂对接
5. **基于OpenID** - 使用微信OpenID作为唯一标识，无需手机号绑定
6. **智能缓存** - 会员状态缓存10分钟，减少服务器压力，提升响应速度
7. **完整对账** - 后端记录所有订单，支持对账、导出和追溯
8. **管理后台** - 提供订单管理、会员管理、数据导出等功能

## 用户体验流程

### 免费用户
1. 打开小程序，自动登录
2. 浏览知识库题目列表（免费）
3. 点击题目查看详情 → 提示开通会员
4. 尝试使用AI功能 → 引导到购买页面

### 会员用户
1. 选择套餐（月度/季度/年度）
2. 保存收款码到相册
3. 打开微信扫一扫 → 相册 → 选择收款码
4. 完成支付（¥29.9/49.9/99.9）
5. 返回小程序，点击"我已完成支付"
6. 系统自动激活会员（调用 member-service API）
7. 使用所有AI功能和查看知识库完整答案
8. 会员状态实时同步（基于OpenID）
