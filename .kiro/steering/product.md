# 产品概述

AI面试助手是一款基于微信小程序的智能职业发展工具，专注于大数据领域的面试准备，帮助求职者提升面试竞争力。

## 核心功能

### AI功能（需会员）

**岗位分析**: 通过AI分析职位描述（JD）或岗位链接，自动提取核心技能、岗位职责，并生成预测面试问题，帮助求职者了解岗位要求和能力差距。

**简历解读**: AI驱动的智能简历分析功能，支持多种文件格式上传（PDF、Word、Markdown），自动解析简历内容，提供优化建议和岗位匹配度分析。用户可以上传最多3个简历文件，系统会持久化存储并支持随时切换分析。基于 DeepSeek AI 提供专业的简历分析、优化建议和 STAR 原则解读，帮助求职者完善简历。

**情绪小屋**: 提供面试压力管理和心理支持，通过AI对话帮助求职者缓解面试焦虑，提供放松技巧和应对策略。

### 知识库（部分免费）

**面试知识库**: 提供结构化的大数据技术面试题库，覆盖10+个主流技术分类（HDFS、Spark、Flink、Kafka、HBase、Hive、MapReduce、Yarn、Zookeeper、Flume等），包含200+精选面试问题和详细答案，支持分类浏览和关键词搜索。

**访问策略**:
- 免费用户：可以浏览题目列表和分类，了解知识库内容
- 会员用户：可以查看完整的题目详情和答案解析

### 简历管理（新增）

**多简历管理**: 用户可以上传最多3个简历文件，系统支持 PDF、Word、Markdown 等格式，自动解析文本内容并持久化存储。

**核心功能**:
- 简历上传：支持 PDF (.pdf)、Word (.doc, .docx)、Markdown (.md) 格式
- 文件大小限制：单个文件最大 10MB
- 简历列表：查看所有已上传的简历，显示文件名和上传时间
- 简历切换：随时切换不同简历进行分析
- 简历删除：删除不需要的简历，释放空间
- AI 智能问答：基于选定的简历进行深度分析和问答

**预设问题**:
1. "整个简历最大的亮点是什么？"
2. "简历还有哪些可以优化的？"
3. "用 STAR 原则解读这份简历"

**技术特点**:
- 智能文档识别：自动判断文档类型（简历、职位描述、报告等）
- 上下文对话：支持多轮对话，保持对话历史
- 专业分析：基于 DeepSeek AI 提供专业的简历分析和优化建议

### 我的收藏（新增）

**收藏管理**: 用户可以收藏、管理和查看来自不同来源的面试问题和答案，支持标签分类和AI生成答案。

**核心功能**:
- 多来源收藏：支持从知识库、简历解读、自定义问题三个来源收藏内容
- 标签管理：为收藏添加标签，支持按标签筛选和分类
- AI生成答案：自定义问题可通过AI生成专业答案（流式输出）
- 分页浏览：支持分页加载，每页20条
- 编辑和删除：支持编辑自定义问题和删除收藏
- Markdown渲染：使用towxml完美渲染答案内容

**会员限制**:
- 免费用户：最多收藏10条
- 会员用户：无限制收藏

**技术特点**:
- 流式输出：AI生成答案采用SSE流式输出，实时显示生成进度
- 自动标签：简历来源自动添加"简历分析"标签
- 实时更新：所有操作后UI立即更新，无需刷新

### 个人中心

**用户管理**: 用户信息展示、会员状态查看、系统设置配置、意见反馈提交等功能。

## 目标用户

- 大数据/数据工程领域的求职者
- 准备技术面试的应届毕业生和在职人员
- 需要简历优化和面试辅导的技术人员
- 面临面试压力需要情绪支持的求职者

## 商业模式

### 会员付费制

用户需要开通会员后才能使用AI功能（岗位分析、简历解读、情绪小屋），知识库功能对所有用户免费开放。

### 会员套餐

- **月度会员**: ¥29.9 / 30天
- **季度会员**: ¥49.9 / 90天
- **年度会员**: ¥99.9 / 365天

### 会员权益

- ✅ 无限次使用所有AI功能（岗位分析、简历解读、情绪小屋）
- ✅ 上传最多3个简历文件，持久化存储
- ✅ 基于 DeepSeek AI 的智能简历分析和优化建议
- ✅ 查看知识库完整答案和详细解析
- ✅ 无限收藏面试问题和答案（免费用户限10条）
- ✅ 无限次数的AI对话
- ✅ 支持多种文档格式（PDF、Word、Markdown）
- ✅ 优先客服支持

### 支付方式

**收款码支付**: 用户选择套餐后，扫描个人收款码完成支付，点击"我已支付"后立即激活会员。

**技术实现**:
- 前端：使用 `utils/member-api.js` 对接统一后端服务，会员信息缓存10分钟
- 后端：统一后端服务（基于OpenID）提供会员状态查询、开通续费、订单记录和对账功能
- 认证：JWT + OpenID 认证机制，微信登录集成
- 存储：会员数据和订单记录存储在 MySQL 数据库中
- AI 服务：集成 DeepSeek API 提供智能问答

### 会员验证

系统会在以下场景验证用户的会员状态：

**AI功能**:
- 有效会员：直接使用功能
- 无效会员：自动跳转到套餐购买页面

**知识库**:
- 题目列表：所有用户可浏览
- 题目详情：需要会员才能查看完整答案
- 无效会员点击题目：提示开通会员并引导到购买页面

## 技术架构

### 前端
- 微信小程序（原生开发）
- Vant Weapp UI 组件库
- 会员API客户端（`utils/member-api.js`）
- 简历API客户端（`utils/resume-api.js`）- 新增
- 收款码支付流程（保存到相册 → 微信扫一扫 → 支付 → 激活）
- 会员状态缓存（10分钟有效期）
- 简历列表缓存（5分钟有效期）

### 后端服务

**统一后端服务 (ai-interview-helper-server)** - 端口 3000，HTTPS 8443
整合了所有后端功能的统一 Node.js 服务：

**核心功能模块**:
- 用户认证（JWT + OpenID）
- 微信登录（wx.login → code2Session → OpenID）
- 会员状态管理（基于OpenID）
- 会员开通和续费
- 订单记录和查询
- 知识库数据API
- 简历管理（上传、存储、列表、删除）
- AI 智能问答（集成 DeepSeek API）
- 静态文件服务（收款码、头像等）
- 管理员接口（订单列表、会员列表、导出）

**技术栈**:
- Express.js 4.x
- MySQL 8.0+ 数据库
- PM2 进程管理
- Nginx 反向代理
- DeepSeek AI API 集成

**生产地址**: https://api.feelnow.cn

**API 路由**:
- `/api/auth/*` - 认证相关
- `/api/member/*` - 会员管理
- `/api/knowledge/*` - 知识库
- `/api/orders/*` - 订单管理
- `/api/resume/*` - 简历管理
- `/api/favorites/*` - 收藏管理（新增）
- `/api/admin/*` - 管理后台
- `/api/upload/*` - 文件上传
- `/static/*` - 静态文件

### 数据存储

**MySQL 数据库 (ai_interview_helper)**:
- `members` 表 - 用户和会员信息（主键：OpenID）
- `orders` 表 - 订单记录（关联 OpenID）
- `resumes` 表 - 简历信息（关联 OpenID，存储文件路径和解析文本）
- `favorites` 表 - 收藏记录（关联 OpenID，存储问题、答案、来源信息）
- `tags` 表 - 标签（关联 OpenID，存储标签名称和使用次数）
- `favorite_tags` 表 - 收藏标签关联（多对多关系）

**文件存储**:
- 知识库数据：JSON 文件（server/src/data/knowledge.json）
- 简历文件：服务器文件系统（server/uploads/resumes/）
- 用户头像：服务器文件系统（server/src/static/avatars/）
- 静态图片：服务器文件系统（server/src/static/images/）

**前端缓存**:
- 会员状态缓存 10 分钟，减少 API 调用
- 简历列表缓存 5 分钟
- 标签列表缓存 5 分钟

1. **专注垂直领域** - 专注大数据技术面试，内容精准专业

11. **完整对账** - 后端记录所有订单，支持对账、导出和追溯
12. **管理后台** - 提供订单管理、会员管理、数据导出等功能

## 用户体验流程

### 免费用户
1. 打开小程序，自动登录
2. 浏览知识库题目列表（免费）
3. 点击题目查看详情 → 提示开通会员
4. 尝试使用AI功能 → 引导到购买页面

### 会员用户
1. 选择套餐（月度/季度/年度）
2. 保存收款码到相册
3. 打开微信扫一扫 → 相册 → 选择收款码
4. 完成支付（¥29.9/49.9/99.9）
5. 返回小程序，点击"我已完成支付"
6. 系统自动激活会员（调用统一后端 API）
7. 使用所有AI功能和查看知识库完整答案
8. 会员状态实时同步（基于OpenID）

### 简历管理使用流程
1. 进入简历解读页面
2. 上传简历文件（PDF/Word/Markdown，最多3个）
3. 系统自动解析简历内容
4. 选择要分析的简历
5. 使用预设问题或自定义问题进行AI问答
6. 查看AI分析结果和优化建议
7. 支持多轮对话，深度分析
8. 可随时切换不同简历进行分析
9. 不需要的简历可以删除
