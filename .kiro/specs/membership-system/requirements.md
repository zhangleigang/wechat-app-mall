# 会员系统需求文档

## 需求概述

实现付费会员制度，用户需要支付费用成为会员后才能使用小程序的核心AI功能。

## 业务目标

- 建立可持续的商业模式
- 通过会员付费获得收入
- 提供差异化的会员权益
- 保证付费用户的优质体验

## 核心需求

### 1. 会员状态管理

**功能描述**：
- 用户分为"未开通会员"和"已开通会员"两种状态
- 会员有明确的有效期（到期日期）
- 会员到期后自动变为未开通状态

**数据字段**：
- 会员状态：是否为会员
- 开通时间：首次开通时间
- 到期时间：会员有效期截止日期
- 会员类型：月度会员/季度会员/年度会员

### 2. 会员套餐设置

**套餐类型**：
- 月度会员：30天有效期
- 季度会员：90天有效期
- 年度会员：365天有效期

**套餐定价**：
- 月度会员：¥29.9
- 季度会员：¥79.9（优惠11%）
- 年度会员：¥299.9（优惠17%）

**套餐权益**：
- 无限次使用岗位分析功能
- 无限次使用简历解读功能
- 无限次使用情绪小屋功能
- 完整访问面试知识库
- 优先客服支持

### 3. 会员开通/续费流程

**开通流程**：
1. 用户点击"开通会员"按钮
2. 展示会员套餐选择页面
3. 用户选择套餐类型
4. 调用微信支付
5. 支付成功后开通会员
6. 更新会员状态和到期时间

**续费流程**：
- 会员到期前7天显示续费提醒
- 会员到期后可以续费（在原有到期时间基础上延长）
- 支持自动续费设置（可选）

### 4. 会员权限验证

**验证时机**：
- 进入岗位分析页面前
- 进入简历解读页面前
- 进入情绪小屋页面前
- 访问知识库详情前

**验证逻辑**：
```
IF 用户未登录 THEN
  跳转到登录页面
ELSE IF 用户未开通会员 OR 会员已到期 THEN
  显示会员开通引导弹窗
  提供"立即开通"按钮
ELSE
  允许访问功能
END IF
```

**非会员限制**：
- 可以浏览知识库分类列表
- 可以查看个人中心基本信息
- 不能使用任何AI功能
- 不能查看知识库详细内容

### 5. 个人中心会员展示

**会员信息卡片**：
- 会员状态标识（已开通/未开通）
- 会员类型（月度/季度/年度）
- 到期时间显示
- 开通/续费按钮

**会员权益说明**：
- 展示会员可享受的所有权益
- 对比非会员的限制

## 技术要求

### 后端接口

**需要的API接口**：
1. 查询会员状态：`GET /api/member/status`
2. 获取会员套餐列表：`GET /api/member/packages`
3. 创建会员订单：`POST /api/member/order`
4. 查询订单状态：`GET /api/member/order/:orderId`
5. 会员开通回调：`POST /api/member/callback`

**基于apifm的实现**：
- 使用apifm的会员卡功能（cardMyList）
- 使用apifm的订单系统
- 使用微信支付接口

### 前端实现

**新增页面**：
- 会员套餐选择页面：`pages/member/packages/index`
- 会员权益说明页面：`pages/member/benefits/index`
- 支付结果页面：`pages/member/payment-result/index`

**修改页面**：
- 个人中心：增加会员信息展示
- AI功能页面：增加会员验证

**新增组件**：
- 会员验证弹窗组件：`components/member-guard/index`
- 会员状态标识组件：`components/member-badge/index`

### 数据存储

**本地存储**：
- 会员状态缓存（减少接口调用）
- 缓存有效期：1小时
- 每次进入小程序时刷新

**服务端存储**：
- 使用apifm的会员卡系统
- 记录会员开通/续费历史
- 记录支付订单

## 用户体验要求

### 引导体验

**首次使用引导**：
- 新用户首次进入显示会员介绍
- 突出会员权益和价值
- 提供"立即体验"按钮

**功能拦截提示**：
- 非会员点击AI功能时，显示友好的提示
- 说明需要开通会员的原因
- 提供快速开通入口

### 支付体验

**支付流程优化**：
- 支付前显示订单确认
- 支付中显示加载状态
- 支付成功显示祝贺页面
- 支付失败提供重试选项

**安全性**：
- 使用微信官方支付接口
- 订单状态实时同步
- 防止重复支付

**优惠活动**：
- 首次开通优惠
- 节日促销活动
- 推荐好友奖励

**会员等级**（未来扩展）：
- 普通会员
- 高级会员

## 验收标准

### 功能验收

- [ ] 用户可以查看会员套餐和价格
- [ ] 用户可以选择套餐并完成支付
- [ ] 支付成功后会员状态正确更新
- [ ] 会员到期时间显示正确
- [ ] 非会员无法使用AI功能
- [ ] 会员可以正常使用所有功能
- [ ] 会员到期后自动变为非会员状态

### 性能验收

- [ ] 会员状态查询响应时间 < 500ms
- [ ] 支付流程完整无卡顿
- [ ] 会员验证不影响页面加载速度

### 安全验收

- [ ] 会员状态验证在服务端进行
- [ ] 前端验证仅用于用户体验
- [ ] 支付接口使用HTTPS
- [ ] 订单信息加密传输

## 风险评估

### 技术风险

- 微信支付接口调用失败
- 订单状态同步延迟
- 会员状态缓存不一致

**应对措施**：
- 实现支付重试机制
- 订单状态轮询查询
- 定期刷新会员状态

### 业务风险

- 定价不合理导致转化率低
- 会员权益不够吸引用户
- 退款纠纷

**应对措施**：
- 进行市场调研确定合理定价
- 持续优化会员权益
- 制定清晰的退款政策
