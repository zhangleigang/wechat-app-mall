## 完整流程测试

### 场景1: 首次使用完整流程

**目标**: 验证新用户从注册到使用的完整流程

**前置条件**:
- 新用户账号（未上传过简历）
- 有效的会员状态

**测试步骤**:

1. **进入页面**
   ```
   操作: 打开简历解读页面
   预期: 
   - 页面正常加载
   - 显示空列表提示
   - 显示上传引导
   ```

2. **上传第一个简历**
   ```
   操作: 点击上传按钮，选择 resume1.pdf
   预期:
   - 文件选择器打开
   - 显示上传进度
   - 上传成功提示
   - 简历出现在列表中
   - 简历自动被选中
   ```

3. **使用预设问题**
   ```
   操作: 点击"整个简历最大的亮点是什么？"
   预期:
   - 问题自动填入输入框
   - 自动发送
   - 显示用户消息
   - 收到AI回复
   - 回复内容相关且合理
   ```

4. **继续提问**
   ```
   操作: 手动输入问题"我的工作经历有什么优势？"
   预期:
   - 消息发送成功
   - 收到AI回复
   - 对话历史正确显示
   ```

5. **查看对话历史**
   ```
   操作: 滚动查看所有对话
   预期:
   - 所有消息按顺序显示
   - 时间戳正确
   - 格式清晰
   ```

6. **导出对话**
   ```
   操作: 点击导出按钮
   预期:
   - 对话内容复制到剪贴板
   - 包含简历信息
   - 包含所有对话
   - 格式易读
   ```

7. **退出并重新进入**
   ```
   操作: 退出页面，重新进入
   预期:
   - 简历列表正确加载
   - 对话历史正确恢复（24小时内）
   - 选中状态保持
   ```

**测试结果**: ✅ 通过 / ❌ 失败

## 附录：自动化测试脚本

可以使用以下脚本进行自动化集成测试：

```bash
#!/bin/bash
# integration-test.sh

echo "开始集成测试..."

# 1. 启动服务
echo "启动后端服务..."
cd server
npm start &
SERVER_PID=$!
sleep 5

# 2. 运行API测试
echo "运行API测试..."
node test-resume-api.js
API_TEST_RESULT=$?

# 3. 停止服务
echo "停止服务..."
kill $SERVER_PID

# 4. 输出结果
if [ $API_TEST_RESULT -eq 0 ]; then
    echo "✅ 集成测试通过"
    exit 0
else
    echo "❌ 集成测试失败"
    exit 1
fi
```

使用方法：

```bash
chmod +x integration-test.sh
./integration-test.sh
```
