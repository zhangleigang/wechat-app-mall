## 2. 简历上传功能测试

### 2.1 正常上传流程

**测试步骤：**
1. 点击"上传简历"按钮
2. 选择支持的文件格式（PDF/Word/Markdown）
3. 等待上传完成

**检查项：**
- [ ] 文件选择器正常打开
- [ ] 显示"正在上传解析..."加载提示
- [ ] 上传成功后显示"上传成功"提示
- [ ] 简历列表自动刷新
- [ ] 新上传的简历出现在列表中
- [ ] 新上传的简历自动被选中（高亮显示）
- [ ] 有触觉反馈（震动）

### 2.2 文件格式验证

**测试文件：**
- PDF文件（.pdf）
- Word文件（.doc, .docx）
- Markdown文件（.md）
- 不支持的格式（.txt, .xlsx, .ppt等）

**检查项：**
- [ ] PDF文件可以正常上传
- [ ] Word文件可以正常上传
- [ ] Markdown文件可以正常上传
- [ ] 不支持的格式显示错误提示："不支持的文件格式"
- [ ] 错误提示清晰易懂

### 2.3 文件大小验证

**测试文件：**
- 小文件（< 1MB）
- 中等文件（1-5MB）
- 大文件（5-10MB）
- 超大文件（> 10MB）

**检查项：**
- [ ] 小文件可以正常上传
- [ ] 中等文件可以正常上传
- [ ] 大文件可以正常上传
- [ ] 超大文件显示错误提示："文件过大，请上传小于10MB的文件"

### 2.4 数量限制验证

**测试步骤：**
1. 上传第1个简历
2. 上传第2个简历
3. 上传第3个简历
4. 尝试上传第4个简历

**检查项：**
- [ ] 前3个简历可以正常上传
- [ ] 上传第3个简历后，上传按钮消失或禁用
- [ ] 尝试上传第4个简历时，显示提示："最多只能上传3个简历，请先删除旧简历后再上传"
- [ ] 提示信息清晰明确

### 2.5 权限验证

**测试场景：**
- 未登录用户
- 非会员用户
- 会员已过期用户

**检查项：**
- [ ] 未登录时点击上传，显示"需要登录"提示
- [ ] 提供"去登录"按钮，点击后跳转到登录页面
- [ ] 非会员时点击上传，显示"需要会员"提示
- [ ] 提供"去开通"按钮，点击后跳转到会员购买页面
- [ ] 会员过期时显示"会员已过期"提示

### 2.6 错误处理

**测试场景：**
- 网络断开时上传
- 服务器错误
- 文件解析失败

**检查项：**
- [ ] 网络错误时显示友好提示
- [ ] 提供"重试"选项
- [ ] 点击重试后重新尝试上传
- [ ] 服务器错误时显示错误信息
- [ ] 文件解析失败时显示提示

## 测试建议

1. **按顺序测试**：建议按照本清单的顺序进行测试，因为后面的测试可能依赖前面的功能
2. **记录详细信息**：发现问题时，记录详细的复现步骤和截图
3. **多次测试**：关键功能建议测试多次，确保稳定性
4. **边界测试**：特别注意边界情况和异常场景
5. **真实环境**：尽可能在真实的微信环境中测试，而不仅仅是开发者工具
