## 🚀 快速开始

### 第一次测试

如果你是第一次进行测试，建议按以下顺序：

1. **阅读测试指南**
   ```bash
   # 查看测试指南
   cat docs/TESTING_GUIDE.md
   ```

2. **准备测试环境**
   ```bash
   # 启动数据库
   mysql.server start
   
   # 启动后端服务
   cd server
   npm install
   npm start
   ```

3. **运行后端API测试**
   ```bash
   # 在server目录下
   node test-resume-api.js
   ```

4. **进行前端测试**
   - 打开微信开发者工具
   - 参考 `FRONTEND_TEST_CHECKLIST.md` 进行测试
   - 记录测试结果

5. **进行集成测试**
   - 参考 `INTEGRATION_TEST_GUIDE.md`
   - 执行完整流程测试
   - 填写测试报告

## 🐛 常见问题

### Q1: 测试脚本运行失败怎么办？

**A**: 检查以下几点：
1. 服务器是否正在运行
2. 数据库连接是否正常
3. 环境变量是否配置正确
4. 依赖是否安装完整

详见 [TESTING_GUIDE.md - 常见问题](./TESTING_GUIDE.md#常见问题)

---

### Q2: 如何模拟网络异常？

**A**: 可以使用以下方法：
1. 微信开发者工具的网络模拟功能
2. Charles代理工具
3. 浏览器开发者工具的网络限速
4. 手动断开网络连接

---

### Q3: 测试数据如何清理？

**A**: 执行以下SQL和命令：

```sql
-- 删除测试简历
DELETE FROM resumes WHERE openid LIKE 'test_%';

-- 删除测试会员
DELETE FROM members WHERE openid LIKE 'test_%';
```

```bash
# 删除测试文件
rm -rf server/uploads/resumes/test_*
```

---

### Q4: 如何进行性能测试？

**A**: 参考以下方法：
1. 使用微信开发者工具的性能分析
2. 记录关键操作的响应时间
3. 监控内存使用情况
4. 测试长时间使用的稳定性

详见 [INTEGRATION_TEST_GUIDE.md - 性能测试](./INTEGRATION_TEST_GUIDE.md#性能测试)
