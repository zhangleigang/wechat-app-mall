# 新用户测试流程指南

## 📋 测试目标

在小程序上线前，通过完整的新用户流程测试，确保所有功能正常工作，没有遗留的bug。

## 🔧 准备工作

### 1. 清理数据库

```bash
# 进入服务器目录
cd server

# 运行清理脚本
node scripts/clean-database.js
```

**注意**：此操作会删除所有用户数据，请确保已备份重要数据！

### 2. 重启服务

```bash
# 重启后端服务
pm2 restart ai-interview-helper

# 检查服务状态
pm2 status
pm2 logs ai-interview-helper
```

### 3. 清理小程序缓存

- 在微信开发者工具中：工具 → 清缓存 → 全部清除
- 或在真机上：删除小程序重新进入
