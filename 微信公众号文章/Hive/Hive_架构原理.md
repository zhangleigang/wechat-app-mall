# 【问题】简述Hive的架构原理

## 【答案】

### 3-5分钟快速回答要点：

Apache Hive是基于Hadoop的数据仓库工具，核心架构包括：
1. **Hive Client**：用户接口，支持CLI、Web UI、JDBC/ODBC
2. **Hive Services**：包括Driver、Compiler、Optimizer、Executor
3. **Metastore**：元数据存储，管理表结构、分区、存储位置等信息
4. **Hadoop集群**：底层存储（HDFS）和计算（MapReduce/Tez/Spark）
5. **HiveQL**：类SQL查询语言，转换为MapReduce/Tez/Spark作业

核心特点是SQL化查询、批处理、数据仓库和与Hadoop生态的深度集成。

#### 二、核心组件详解

**1. Hive Driver**

Driver是Hive的核心组件，负责接收查询、编译和执行。
